# Mi Lista M3U - Plugin para CloudStream

1. Cambia `LIST_URL` en `M3uProvider.kt` por la URL de tu lista M3U/IPTV.
2. Sube este proyecto a un repositorio de GitHub basado en cloudstream-extensions-template.
3. La acción de GitHub genera el archivo .cs3 automáticamente.
4. En CloudStream: Ajustes → Extensiones → Añadir repositorio.

Usa solo listas de fuentes que tengas derecho a ver.
